# Antislop UI Audit 001 (2026-11-24)

Cakupan audit: perubahan UI Multi TV (`MultiStreamScreen.kt`) dan Live TV multi-select (`LiveTvScreen.kt`) sesuai Mode 2 (After).
Sesuai aturan Mode 2, belum ada file kode yang diubah untuk temuan di bawah ini sebelum Anda memilih nomor mana yang ingin diperbaiki.

## Temuan Bernomor

1. **[HIGH - R-03] Target sentuh chip & pill di bawah 44dp pada layar ponsel**
   - File: `MultiStreamScreen.kt` (`DockToggleChip`, `CompactActionPill`, dan slot pill kanan bawah)
   - Alasan: Padding vertikal `5.dp`-`6.dp` dengan teks `10.sp`-`11.sp` tanpa `heightIn(min = 44.dp)` menghasilkan tinggi tombol ~28-32dp, sehingga kurang nyaman ditekan dengan jari di layar sentuh.

2. **[HIGH - R-25] Kontras teks `AccentBlue` di atas `AccentBlueSoft` dan `TextMuted` di atas `BgSurface` di bawah 4.5:1**
   - File: `Color.kt`, `MultiStreamScreen.kt`, `LiveTvScreen.kt` (`Slot` pill aktif, `DockToggleChip` aktif, dan label status `Kosong`)
   - Alasan: `AccentBlue` (`#2979FF`) di atas latar gelap semi-transparan (`BgDeep`/`BgSurface` + `AccentBlueSoft`) menghasilkan rasio kontras di bawah 4.5:1 untuk teks kecil `9.sp`-`11.sp`; sebaiknya pakai `ElectricBlue` (`#448AFF`) / `TextPrimary` untuk teks aktif agar lolos WCAG AA.

3. **[HIGH - R-37] Belum ada dokumen arah desain (`DESIGN.md`) dengan dial ENERGY / RHYTHM / MOTION**
   - File: root proyek `DINS-PLAYER`
   - Alasan: Tanpa `DESIGN.md`, perubahan UI belum memiliki acuan dial tertulis, sehingga berstatus draf antarmuka.

4. **[MEDIUM - R-04] Penggunaan `Icons.Default.Star` untuk aksi "Utama" tanpa alasan spesifik konten**
   - File: `MultiStreamScreen.kt` (`SelectedSlotActionChips`)
   - Alasan: Ikon bintang bersifat generik untuk tombol pemindah posisi slot; ikon seperti `Icons.Default.PictureInPictureAlt` atau `Icons.Default.CenterFocusStrong` lebih langsung menggambarkan aksi memindahkan preview ke layar fokus utama.

5. **[LOW - R-11] Variasi border radius kurang terstruktur antar elemen HUD (6dp, 8dp, 10dp, 12dp, 14dp, 24dp)**
   - File: `MultiStreamScreen.kt` (`StreamTile`, `DockToggleChip`, `MultiHud`, unlock pill)
   - Alasan: Banyak nilai radius berbeda dipakai berdekatan; menyederhanakan ke 3 tingkat konsisten (misal `8.dp` kontrol/chip, `12.dp` tile/kartu, `14.dp` kontainer panel) memperjelas hierarki visual.
